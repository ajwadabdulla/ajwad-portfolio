## ðŸš€ How to Host Free on Vercel

This portfolio is built with **React + TypeScript + Tailwind CSS** and is 100% frontend-only. It deploys automatically on Vercel with zero server configuration.

### Option A: Deploy via GitHub (Recommended)
1. Push this folder to your GitHub account:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository.
4. Vercel automatically detects **Vite**:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. Click **Deploy**. Your portfolio will be live in ~30 seconds with a free `.vercel.app` domain and free SSL!

### Option B: Deploy via Vercel CLI
If you have Vercel CLI installed:
```bash
npm i -g vercel
vercel
```
